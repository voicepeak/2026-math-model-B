# 方案二 · gemini —— 7 点六边形 + 全息批感知 + 正交基线交会

## 算法要点
1. **7 点覆盖**：原点 + 半径 `1200 m` 正六边形外圈（方案给出的覆盖证明：最大盲区 `968.9 m < 1000 m`）。
2. **多信道全息批感知**：在原点（及外圈节点）一次性批量扫描全部存活信道，用零位移换取全场多目标初始方位。
3. **正交基线第二测点**：对每个已发现目标，从观测点前出 `700 m`、侧移 `450 m` 取第二测点，使交会角接近正交，力争 2 次测向即可清除。
4. **环形推进**：原点批次后沿外圈 6 点推进，不清除则不回退。

## 与原始策略的差异
- 覆盖点 17 → 7；
- 由“发现一个跑一次”改为原地批量感知后统一交会；
- 第二测点由固定横移改为正交大基线设计。

## 安全实现说明（测试时请注意）
- 原方案代码在两次交会后**直接**在估计点清除；本实现保留了 `r ≤ 19.9 m` 的认证判断，若两次测向不足则继续用原认证定位迭代，最后仍有条带兜底。**这样不会因估计偏差导致清除失败。**
- 离线多轮 100% 清除。

## 官方演练怎么跑
1. 打开官方模拟器并登录，选择“**问题3演练测试**”，等待界面显示接口就绪。
2. 在本文件夹打开终端：
   ```powershell
   python run_robot.py --mode q3 --robot-id 实际参赛队号
   ```
   端口不同时加 `--url http://127.0.0.1:端口`。
3. 结果在 `windows_results/时间_q3_随机串/summary.json`。
