## 如何在本机运行

1. 在官方模拟器选择“问题4演练测试”，等待接口就绪。此程序不启动测试，不选择正式测试。
2. 在本目录打开终端，执行（把参数替换成自己的参赛队号）：

```powershell
python run_q4.py --robot-id 你的参赛队号
```

若电脑只有py启动器，可用 `py -3 run_q4.py --robot-id 你的参赛队号`。在线程序只需Python标准库。默认连接127.0.0.1:2026；可用`--url`修改。输出在`windows_results_q4/`，含summary、client.jsonl、trace与清除证书。退出码0表示程序完整完成，2表示错误或预算停止；后一种不能宣称全清。不要使用研究原型`run_robot.py`作为最终入口。

`official_total_sources`保持空值，演练结束后以官方界面的源总数核对清除比例。正式测试加密日志仍须在官方模拟器导出，本程序不会伪造日志或正式案例编码。

## 核心变化与比较范围

- 25点环形定向覆盖：原点、998米内环8点、1838米外环16点。32三角片铺满外环，最大边998米，外环内切半径1802.683米。每个源位于某片内，任意180度发射方向至少看得到一个片顶点。Fraction比较核验固定坐标的边长、面积和外边界。
- 各频道持久保存有界误差楔形交会区域，停靠共享测向；未知频道先批扫，再联合安排定位与覆盖路径。
- 多起点最近邻/2-opt滚动路线。包围圆≤19.9米认证清除；≤60米可做一次光学尝试，只有公开success计清除。收集两次方位后可对当前可行多边形的紧包围矩形作光学扫查；每格≤28×28米，距离覆盖半径<20米。
- no_signal不用于排除第四题位置圆；目标未知总数不参与策略。只有覆盖节点全部完成、已知目标全清，或已清到题定上界16个，才完整停止。

共比较31个配置（含基础版）：最近邻、2-opt、多起点、模拟退火、Held–Karp DP，以及覆盖网格、局部恢复、光学阈值、共享基线、旋转和扫描点替换消融。首轮/第二轮/第三轮分别保留`screening*.json/csv`，失败/未获证布局保留在`layout_search.json`。四个决赛候选使用40个开发场景后按预定加权时间指标选定；冻结后未依留出结果调参。

## 全局最优：已证与未证

对于固定25扫描点、从原点起步、终点自由的行走距离，整数规划＋子回路割得到 **17942.133272974348米**，HiGHS在数值容差内报告primal=dual、gap=0。独立质检检查模型、点集与路径长度；未用独立求解器重求dual。这只是固定点路线的最优性，不覆盖未知源位置、测向、定位绕行或在线决策。

`optimality.py`还精确求解合成真值中心的开放TSP，构造离线乐观下界：L≥max(0,L_center−40N)，T≥L/5+5N。真值只用于离线下界分析。现有最终策略与下界仍有间隙，因此**尚未证明或实现整个第四题在线问题的全局最优**。

## 复现与文件

研究图表复现需`requirements-research.txt`依赖。运行：

```powershell
python reproduce.py
```

该命令核对冻结哈希，重跑40开发＋100留出＋80压力的两策略配对，运行私有随机端口HTTP模拟自测，重建结果和9张图并执行严格图审。在线算法不会并发动作；这里只对独立离线场景采用4进程。`python reproduce.py --verify-only`执行缩小重放、重新计算统计与图表并验证保存研究。完整复现可能需数分钟到十余分钟，取决于机器。
