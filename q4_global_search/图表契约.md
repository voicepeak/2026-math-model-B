# 第四题图表契约

范围只含 q4。本次图均为本地合成研究结果，不混入官方五次成绩计算改进比例。Python/matplotlib后端，英文轴标，中文说明放README。默认单幅6.4×4.0英寸；轨迹对照为7.2×3.6、压力分组为7.2×4.2、31配置比较为6.4×8.6英寸。导出300dpi PNG和文字可编辑SVG、灰度预览；来源数据、精确重跑入口一并交付。策略对照使用蓝色表示基础版、橙色表示候选版，并用线型/点型冗余编码；耗时分解图的颜色表示动作类别，图例逐项说明。算法比较图的灰点表示单个场景，菱形表示总耗时除总源数。

核心结论：比较多种在线路线与覆盖策略后，冻结候选能否在未调参留出集和定向压力集保持全清并降低整体耗时。结论仅从final数据计算。
