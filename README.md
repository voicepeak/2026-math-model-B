# 2026 数学建模竞赛 B 题参赛作品（开源）

本仓库为 2026 年全国大学生数学建模竞赛 B 题的参赛作品开源版本，收录**最终提交的完整论文**与**支撑材料**（可独立运行的完整源程序、正式测试必交文件、论文结果数据）。

> 本 README 只说明仓库结构与复现方式，不涉及题目内容与求解细节；题目与模型细节见论文正文。

## 仓库结构

```
.
├── 完整论文.pdf                 # 最终提交的完整论文
├── AI工具使用详情.pdf            # AI 工具使用情况说明（必交附件）
├── README.md                    # 本文件
├── README_复现说明.md            # 支撑材料详细说明
├── requirements.txt             # 环境依赖说明
├── verify_submission.py         # 提交包自检脚本
├── submission_manifest.json     # 全包文件 SHA-256 清单
├── 问题一与问题二/               # 问题一、问题二：代码 + 结果数据
│   ├── code/
│   └── results/
├── 问题三/                       # 问题三：在线入口、策略继承链、回归测试
│   └── code/
├── 问题四/                       # 问题四：在线入口、策略族、证书与自测
│   └── code/
└── 正式测试/                     # 正式测试必交文件
    ├── 加密日志/                 # 六份正式测试加密日志
    ├── 客户端记录/               # 六场正式测试客户端日志与汇总（已匿名）
    ├── official_results_to_fill.csv
    └── formal_timing_evidence.json
```

每个问题目录均**自包含**：公共几何与接口模块在各问题目录中各保留一份，单独取出该目录即可运行。

## 环境要求

- Python 3.12 或以上（在线算法与核验脚本仅使用标准库，无需第三方依赖）。

如需重绘论文图表或重跑统计，额外依赖见 `requirements.txt`。

## 快速核验

在仓库根目录执行：

```powershell
python verify_submission.py
```

核验内容包括：包内文件 SHA-256、问题一与问题二的几何/网格结果、问题三策略回归测试、问题四离线精确覆盖审计与 HTTP 协议自测。

全部通过时末行输出 `PASS`。核验在临时副本中进行，不修改本仓库。
