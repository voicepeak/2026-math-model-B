# 第三问：共享基线与弹性覆盖路线

本目录独立可运行，冻结候选为`combo100`。算法只读取官方公开动作反馈，不知道源总数、位置、接收半径或误差种子。原点扫描后用100米共享基线改善多个已知源的交会位置；随后将目标与六个覆盖点联合排路，并在连续圆域覆盖保持成立时移动未访问的覆盖点。每频道最多一次半径50米内光学试探，失败继续测向和认证定位；只统计公开返回success的清除。19.9米包围圆认证、near与完整条带兜底均保留。

40个开发场景（种子1..40）全清526源，平均229.368秒/源。此数值是调参开发结果。100个新留出场景20001..20100和50个压力场景的最终对比以`探索结果.md`及`results/comparison_metrics.json`为准。200秒/源是探索目标，不能作为保证或已证明下界。尚未执行本候选的官方演练或正式测试。

## 本地复现

Python 3.12+；在线算法只用标准库，完整证据图另需numpy、pandas、matplotlib、Pillow。PowerShell在本目录执行：

```powershell
python reproduce.py
```

唯一命令会依次运行回归测试、40开发+50压力+100独立留出配对验证、本地HTTP五局自测、九张证据图、图审和哈希复现清单。不会连接官方模拟器。已有实验失败和退化方案保留在`prototype_v1.py`至`prototype_v10.py`和`results/screening*.json`；全部探索批次也可用`python reproduce.py --research`复跑。仅重建报告和图表用`python reproduce.py --analysis-only`，不代替全量验收。

快速本地测试：

```powershell
python benchmark.py --seeds 1 --algorithms breakthrough,ultimate --out quick
python selftest.py --seeds 211,212,213,214,215
```

## 官方演练入口（用户自行启动）

在官方模拟器选择问题3演练、确认接口就绪后，才运行：

```powershell
python run_robot.py --robot-id 你的实际参赛队号
```

端口不同追加`--url http://127.0.0.1:端口`。不能把本地合成全清解释为官方100%通过；演练结束需人工绑定官方给出的总数。程序不自动消耗正式测试次数，本研究未调用该入口。每局保存公开请求响应、动作、清除证书与summary；官方加密日志仍需由官方模拟器导出，保持原名。

## 证书与结果解释

- `complete_coverage`：原点扫描完成，扫描圆在1800米圆周上的区间合并覆盖整周；用于覆盖的外圈测点半径≤1660米，径向距离平方凸性确保1000..1800米之间也全覆盖，且全部已知源清除。
- `complete_upper_bound`：已成功清除16个不同频道，达到题定总数上界；可提前结束，无需完成剩余扫描点。
- `not_yet_complete`覆盖标签在上界退出时合法，不能用该标签否定上界证书；其余非complete状态是未完成。
- 旧`uncovered_cells`为保守100米方格诊断，不是本算法的退出判据。
- 试探clear失败允许耗时3秒，但不算成功；失败数与所有逐局退化均在结果中保留。
