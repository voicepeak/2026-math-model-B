# 第三问：200秒/源探索记录

本轮仅在 q3_ultimate200 内开展研究，父目录算法、论文、官方日志和 q3_breakthrough 均只读。200秒/源是平均表现目标，不是所有合法布局的保证或已证明下界。输入来自上两级题目文本、附件1和附件2；使用公开 measure / clear 返回值，不向策略提供真实位置、接收半径、源总数或误差种子。

## 可复现模型增量

1. 可见性约束：频道固定接收半径 R 在 [1000,1500]。有信号位置 s、无信号位置 n 满足 |g-s| <= R < |g-n|，故 2(n-s)·g <= |n|²-|s|²。无信号还排除以 n 为中心的1000米圆。圆外可行集取保守凸包，允许丢失信息，但不能丢失真值。仍保留1.005度实现误差裕度。
2. 连续覆盖：以外接72边形包含整个1800米圆域，将其按实际完成全频道扫描的位置划分Voronoi单元。每个单元的距离平方是凸函数，最大值出现在顶点。所有单元顶点距对应测点均小于1000米，才能宣布连续全域已覆盖。离散采样只用于路径规划。
3. v1：将已知目标中心预测为未来扫描位置，按增益/路径成本贪心插入测点；任何有至少4个新样点的沿途停点都批扫。P1通过，但10场景281.943849秒/源，差于基准251.254481；保留prototype_v1.py和results/prototype_v1.*。
4. v2：从完整六边形模板开始删冗余点，只在清除完成的停点、预计节约移动足以支付全部频道检测费时批扫。尝试不同模板相位。允许一次半径50米内的光学试探，必须以公开success才算清除；失败则继续原认证交会与条带兜底。
5. v3：固定六点结构不变，按初始公开观测旋转与调整半径。半径区间1125..1730米可由 r_target∈[1000,1800] 的端点距离界证实完整覆盖。初始最小案例表现退化，不因此删结果。
6. v4：剩余扫描节点单调减少，只有“已经扫描位置 + 当前清除点 + 删点后剩余节点”通过连续覆盖证书且节省移动支付扫描费时才进行替代，避免后期碎片修补。
7. v5：可行域MEC半径达到阈值时，最多一次去中心光学尝试；若失败，在同位置再测向，不能把失败当清除。
8. v6：六个未访问覆盖点沿联合路线做局部移动，每次必须保持圆周区间连续覆盖。首次P1发现真实圆域证书与更大的外接多边形终检合同不一致，导致一个真实全清案例异常；保留p1_review/v6_failure.json，修复后用相同圆弧径向合同完成终检并通过P1。
9. v7：原点全扫后，利用公开可行域选择一条共享100/200/300米基线，统一复测已知频道，先改善目标估计再规划路线。共享点不算全频道覆盖扫描。
10. v8：当前可行多边形最长弦取5个内部样点，用假想零误差观测估计候选测点的移动与后续定位代价。只作为启发式，不是最坏误差保证。
11. v9：前移100/150/200米、横移40米短基线与1150米覆盖环，10局筛选约245秒/源，未优于共享基线候选。
12. v10：组合v6的弹性覆盖与v7的共享基线，保留50米光学尝试；清到16后不再共享测量。40个开发场景全清526源，combo100为229.367817秒/源，combo200为230.022736秒/源。
